### Running-text claims not formalized or partly formalized

- claim, congp.tex:520 (partly): As in the book's own lemma, the formalization proves this for decidable groups (lem:wedgeofgpoidisgpoid). For arbitrary groups, the book does not prove the groupoid property of the wedge. This property would follow from Wärn's theorem (see line 767). It is a hypothesis of sum_of_groups (module 843). The status stays partly for the reason given at line 767.
- claim, congp.tex:767 (not formalized): Not formalized. Wärn's theorem says that B F_S is a groupoid for an arbitrary set S. More generally, it says that a pushout of groupoids along 0-truncated maps is a groupoid. This theorem is not tractable here. Every known proof (Wärn 2023, the zigzag construction) presents identity types of pushouts as sequential colimits of explicit approximations. That needs a sequential-colimit signature, because the pinned Narya has no HITs. It also needs the commutation of sequential colimits with Σ and identity types, and the zigzag induction. This is a development of a size comparable to a chapter. Encode–decode with reduced words, as used here, needs decidable equality of S to define ρ_S. The lemma reduction_function_decidable_equality shows that a reduction function exists iff S has decidable equality. Our torsor-style construction (877) also needs it. With S arbitrary, it is not even possible to construct an instance of FreeGroupSignature without HITs. Only the decidable case is formalized (free_signature_groupoid). The declaration free_infty_group covers arbitrary S as an ∞-group.
