## Corrections to the book

- `xca:conj`, absgroup.tex:232 (slip; the intended statement is proved): Typo in the example display: the second factor must be g·s'·g⁻¹, not g·s·g⁻¹. The exercise itself is true (abstract_conj_mul, abstract_conj_iso). The literal display fails in Z (abstract_conj_printed_instance_fails).
- `ex:conjhom`, absgroup.tex:378: Refuted as printed in one point: the phrase 'similarly for elements in H, giving rise to precomposition with conjugation by h' is false. Transport along conj^h : H = H in X ↦ absHom(X, K) is precomposition with (conj^h)⁻¹ = conj^{h⁻¹} (abstract_conj_transport_precompose). Precomposition with conj^h fails for H = K = abstr Σ₃, f = id and h = τσ, the 3-cycle 0 ↦ 1 ↦ 2 ↦ 0 (here τ = (0 1) and σ = (1 2)): it would give 2 = 0 in Fin 3 (abstract_conj_transport_precompose_printed_fails, module 731). The rest holds. The map conj^g is an element of absHom(G, G), an isomorphism and an identification (abstract_conj_hom / _iso / _path, module 723). Transport along conj^g in X ↦ absHom(H, X) is postcomposition with conj^g (abstract_conj_transport_postcompose). Applied to (id_BG, g⁻¹), abstr gives conj^g (abstr_conj_hom_is_abstract_conj). Applied to USym(inn)(g), abstr gives the identification conj^g of abstr G (inn_abstr_conj_path, module 730).
- `xca:abs-homgroup`, absgroup.tex:406: Refuted as printed: for given G and H, the 'if' direction is false. This direction says: if all pointwise products f·g of homomorphisms H → G are homomorphisms, then G is abelian. For the trivial group H, every such product is a homomorphism, because all of them are constant at e. This is also true for the non-abelian G = abstr Σ₃ (pointwise_products_hom_fixed_domain_fails, module 729). The formalization proves these statements instead. If G is abelian, then f·g is a homomorphism for every H (abelian_pointwise_mul_hom). If s ↦ s·s = id·id is a homomorphism G → G, then G is abelian (square_hom_abelian). Thus G is abelian if and only if all pointwise products of homomorphisms G → G are homomorphisms (abelian_iff_pointwise_products_hom). Also, G is abelian if and only if this holds for all H (pointwise_products_hom_all_abelian).
