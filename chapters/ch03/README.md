## Corrections to the book

- `xca:cancel-surjection`, circle.tex:3104: The printed claim, stated for all types Y, is false. The formalization refutes it. The counterexample uses A = Unit, B = Y = TwoSets and p the inclusion of the base point. Here TwoSets is the groupoid of two-element sets. The map p is surjective (two_sets_base_surjective). The identity and the constant map at the base agree after precomposition with p (two_sets_base_restrictions_equal). But they are not equal (two_sets_identity_not_constant). Thus ap(− ∘ p) is not an equivalence (surjection_cancellation_counterexample implies Empty). Also, two_sets_groupoid shows that Y is a groupoid. Thus the claim already fails one level above sets. Another counterexample uses Y = Type, the universe, with the tautological family and the constant family at Bool. It is surjection_cancellation_universe_counterexample. The corrected statement, with Y a set, is proved separately (cancel_surjection_into_set, with the book's map ap). It does not replace the printed claim. Module 285 formalizes the general form. Let p be n-connected (n = k-1 >= -1) and Y an (n+1)-type. Then ap_{-p} : (f = g) → (fp = gp) is an equivalence whose map is literally ap_{-p} (cancel_n_connected). The proof uses HoTT book Lemma 7.5.7 for families of n-types (n_connected_sections_equiv). The declaration cancel_surjection_into_set is its n = -1 case, equal as an equivalence (cancel_surjection_into_set_minus_one_case).
