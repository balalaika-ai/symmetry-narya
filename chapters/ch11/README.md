## Corrections to the book

- `lem:gens-gp-iff`, fggroups.tex:162: The definition is ρ_S(t) = (t = sh_G, s ↦ (p ↦ ι(s)·p)) with ι(s)·p = concat p (ι s). The formalization proves the 'only if' direction (gens_gp_only_if). It identifies ρ_S with Ev ∘ Y, where Y is the representable family restricted along Bφ. This is an embedding because Bφ has connected fibers. The 'if' direction is false as printed. Take S = ∅ and G = Σ_2. Then ρ_∅ is t ↦ (t = sh), up to the contractible second component. This is an embedding, because a 2-element set A is equivalent to (Fin 2 = A). But ∅ does not generate Σ_2 (gens_gp_if_counterexample). The lemma gens_gp_if_refuted negates the general implication. The book's proof is 'TBD'.
- theorem (no label), fggroups.tex:924: The printed statement has a typo (X and Y are mixed up), and it is false. We use X ⊆ F(S) as a predicate on reduced words. Counterexample: the inverse automaton with two vertices and no edges has an empty reduced language, which is not a coset (fgauto_coset_automata_counterexample). The corrected statement is proved. X is a coset Hw of a finitely generated H iff X is nonempty and X = rho(L(A)) for a finite inverse automaton A. Here A is deterministic, with reverse edges and an initial and a terminal vertex. Direction '=>' uses the Stallings automaton of H with a hair for w. Direction '<=' takes H generated by spanning-tree loop words, and it does not need determinism.
- theorem (no label), fggroups.tex:946: The second sentence is false as printed. H = <a> in F(a,b) has a one-vertex S(H), which is vertex-transitive. But b a B is not in H, and refl computes this with the 932 decision procedure. The corrected statement is proved. If S(H) is total (finite index, 844), then H is normal iff S(H) is vertex-transitive. Here an automorphism is a bijection of the vertex set that preserves and reflects labelled edges. The first sentence is NOT formalized. It says that conjugacy of finitely generated subgroups is decidable, with the proof 'cores equal'. The formalization has no core graphs, and this gap is noted.
