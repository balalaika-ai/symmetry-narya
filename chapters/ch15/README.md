## Corrections to the book

- `defn:algebraic-element`, galois.tex:126: WRONG AS PRINTED (status refuted, corrected version principal). The printed proposition is ‖Σ_n Σ_{a : ⟦n+1⟧ → k} i(a(0)) + i(a(1))α + ⋯ + i(a(n))αⁿ = 0‖ (IsAlgebraicElementAsPrinted). It allows the zero polynomial. Thus every element of every extension is algebraic (every_element_algebraic_as_printed, n = 0, a = 0). As a result, the first claim of rem:algebraic-endomorphisms-are-automorphisms is false as printed (printed_algebraic_t_equiv_fails, counterexample 𝔽₂(X), X ↦ X², module 1532). The corrected notion is IsAlgebraicElement: the same proposition with a(n) ≠ 0, that is, α is a root of a nonzero polynomial of degree n. poly_value computes a(0) + a(1)x + ⋯ + a(n)xⁿ with Fin(n+1) in standard order (inr ★ = index n) and x^m = 1·x⋯x.
- `rem:algebraic-endomorphisms-are-automorphisms`, galois.tex:141: REFUTED AS PRINTED. With the printed defn:algebraic-element, every extension is algebraic. Thus the first claim would make t an equivalence for every extension. printed_algebraic_t_equiv_fails refutes this with 𝔽₂(X)/𝔽₂ (module 1532). Here 𝔽₂(X) is the fraction field of 𝔽₂[X]. The Frobenius x ↦ x² is an 𝔽₂-endomorphism, and X is not a square by parity of valuations. Also, t is an equivalence only if every k-endomorphism is an equivalence (galois_t_equiv_endo_is_equiv). In the same way, the second claim cannot hold as printed (printed_non_algebraic_impossible). Corrected first claim (principal): algebraic_galois_t_equiv_dec shows that t is an equivalence for algebraic extensions with decidable equality of K. algebraic_galois_t_equiv gives the same result under excluded middle. The proof needs the decision only to search finite lists of roots. A fully constructive proof is not known here. Corrected second claim: the formalization does not construct ℚ and ℝ. Consider any extension with RationalSeparation: x < y iff y − x is the square of an invertible element, and elements in the same rational intervals are equal. For such an extension, every k-endomorphism is the identity (real_like_endo_identity). The proof uses the strict order, not the book's non-decreasing + irrational case. Thus t is an equivalence. The non-algebraicity of ℚ → ℝ is a hypothesis of algebraic_converse_fails.
